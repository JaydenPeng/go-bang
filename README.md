# Web 版五子棋游戏

这是一个基于 Vue 3 和 Vite 开发的 Web 版五子棋游戏。

## 功能介绍
- 支持双人对战，玩家可以在浏览器中进行五子棋游戏。
- 使用 HTML5 Canvas 或 SVG 进行棋盘和棋子的绘制。
- 具备基本的游戏规则判断，当有一方连成五子时判定获胜。

## 技术栈
- **前端框架**：Vue 3
- **编程语言**：TypeScript
- **构建工具**：Vite
- **UI 库**：Element Plus（可选）
- **绘图工具**：HTML5 Canvas 或 SVG

## 安装与启动
### 安装依赖
```bash
npm install --registry=https://registry.npmmirror.com
```

### 启动开发服务器
```bash
npm run dev
```

### 构建项目
```bash
npm run build
```

### 预览项目
```bash
npm run preview
```
